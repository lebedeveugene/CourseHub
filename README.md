# CourseHub — платформа онлайн-курсів

Наскрізний навчальний проєкт з дисципліни «WEB-програмування».

**Група:** КІ-24  
**Варіант:** 9

## Опис проєкту

CourseHub — вебплатформа для онлайн-навчання, яка дозволяє переглядати навчальні курси, ознайомлюватися з уроками та записуватися на навчання.

## Основні можливості

- Перегляд каталогу онлайн-курсів.
- Пошук і фільтрація курсів.
- Перегляд інформації про курс та його уроки.
- Реєстрація студентів на курси.
- Керування навчальними матеріалами.

## Стек технологій

Заплановані технології:

- HTML5
- CSS3, Bootstrap 5
- JavaScript, TypeScript
- React
- Node.js, Express
- MySQL
- Git, GitHub
